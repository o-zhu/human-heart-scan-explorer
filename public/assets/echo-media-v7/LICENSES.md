# Echo reference media licenses and modifications

The clips and posters in this directory are independent educational ultrasound
references, not images of the HiP-CT specimen. They are not spatially registered
or heartbeat-synchronized with the static CT volume.

## TEE: Nazerian et al., The Ultrasound Journal (2020)

Files `tee-me4c`, `tee-melax`, `tee-me2c`, `tee-bicaval`, and `tee-tgpapillary`
(`.mp4` and `.webp`) derive from supplementary videos 1a–1e of
**Nazerian et al. (2020), The Ultrasound Journal 12:41**:
<https://link.springer.com/article/10.1186/s13089-020-00189-0>.

These derivatives retain **Creative Commons Attribution 4.0 International**:
<https://creativecommons.org/licenses/by/4.0/>.

Changes: silent H.264 MP4 conversion; all recorded frames and original 25 fps
cadence retained. Black margins were trimmed at native pixels using the complete
recording's visible-content union plus a safety margin. No sector, depth marks,
Doppler overlay, or other visible annotations were removed. No enlargement or
motion interpolation was used. Posters use one native-size frame. These are
published clinical teaching loops; the article does not designate each one as
a normal study. The authors do not endorse this application.

The adjacent catalog `../echo-media-v6.json` (version `echo-media-v7`) records
per-file source URLs, hashes, exact crop bounds, dimensions, frame counts, byte
sizes, licenses, and modifications. This notice concerns these media assets;
it does not change the software license.
