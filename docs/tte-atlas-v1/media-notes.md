# TTE clinical media source review

Reviewed: 2026-11-07. Scope: all 28 named acquisitions in Table 2 (printed pages 19–25) of the ASE adult comprehensive TTE guideline. There are 30 corresponding official supplemental videos, 39–68; rows 2.17 and 2.23 each contain two examples. The document is the 2019 guideline, despite the 2025 upload path.

## Integrated sources

- **30 external TECHmED YouTube cine entries** cover every named Table 2 acquisition and both extra examples. Each iframe ID was observed on the corresponding teaching page. YouTube oEmbed returned the exact view title and TECHmED author for all 30. External player URLs use the same verified IDs on youtube-nocookie.com. Full playback and original recording resolution have not been independently decoded.
- **30 actual sonographic thumbnails** are available as still fallbacks. Each was fetched successfully, decoded as JPEG, measured at 480 × 360 pixels, and visually inspected in a contact sheet. These dimensions describe the thumbnail, not the source video. Source videos should be preferred over thumbnail previews.
- The first TECHmED PNG on each view page is an **anatomical illustration**, not a real ultrasound still. Visual QA caught this distinction; all such PNGs were removed from clinical `clips` and retained separately as `illustrationReferences`.
- **University of Toronto / University Health Network Virtual TTE** provides 20 institutional standard views, with real cine sprite sheets and probe/plane teaching. The catalog includes matching institutional alternatives for 26 Table 2 rows; exact named standard planes, broader standard planes, and related acquisitions are distinguished. The posterior-angulated A4C and LA/pulmonary-vein focus have no exact Toronto alternative in that 20-view module.
- Existing licensed local CardioNetworks and POCUS Atlas recordings remain in the application’s original catalog and can be selected as additional clinical examples. This work did not replace or relabel those files.

## Official guideline recording access

[ASE guideline PDF](https://www.asecho.org/wp-content/uploads/2025/07/Guidelines-for-Performing-a-Comprehensive-Transthoracic-Echocardiographic-Examination-in-Adults.pdf)

[Original JASE article](https://www.onlinejase.com/article/S0894-7317(18)30318-3/fulltext) · DOI 10.1016/j.echo.2018.06.004 · PII S0894731718303183.

The official video numbering was verified against Table 2. Publisher article access and the correctly identified sampled CDN URL returned HTTP 403 in this environment. No guessed publisher MP4 path is offered as a verified playable asset; no official recording resolution or decoded playback is claimed. Official source links and exact video numbers remain attached to every clinical acquisition. TECHmED files are not asserted to be the original ASE/JASE supplements.

## Reuse and provenance

TECHmED content has no redistribution license established in this review. Clinical media is referenced through the source-provided external player or externally hosted thumbnail; no TECHmED/YouTube media bytes are included in the public app assets. YouTube metadata and thumbnail access do not guarantee playback in every browser. The original teaching page remains linked.

The Toronto viewer states © University Health Network 2020, all rights reserved. Its direct sprite URLs are documented for source traceability; use its institutional viewer link rather than mirroring source sheets. Source JavaScript defines 390 × 350 ultrasound frames. PLAX and A4C sheets were fetched at 9750 × 700 pixels, 25 frames, with two label-state rows; one A4C frame was visually inspected. Other frame-path mappings were read from the official viewer but not individually fetched. No invented per-view query string or hash is used; visitors choose the named view in the viewer.

All recordings are independent of the fixed donor heart reconstruction. Acquisition-label correspondence does not establish clinical validation, patient-specific registration, synchronized heartbeat, or exact landmark correspondence to the specimen.
